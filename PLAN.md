# PLAN — Reps (working title, one constant in `js/config.js`)

Mobile-first offline PWA of 45–90s mental-skill games. Vanilla ES modules, no deps, no bundler.

## Files
- Root: `index.html manifest.webmanifest sw.js package.json README.md CLAUDE.md PLAN.md`
- `css/`: `tokens base components games`
- `js/config.js js/main.js`
- `js/core/`: `prng events clock format storage rating srs scoring benchmarks daily achievements progress audio haptics juice loop router ui`
- `js/games/`: `registry.js hud.js` + `quickmath ballpark sure wordbank stroop` (each `index.js logic.js view.js`), `dummy` (debug), `oddscheck` (stretch)
- `js/screens/`: `home gameShell results daily stats settings`
- `data/`: `tf-questions ballpark-bank decks/{finance,italian,russian}`
- `tests/` one file per core module + per game logic + content validators + sw
- `scripts/`: `check.mjs gen-sw.mjs make-icon.mjs smoke.mjs`; `docs/`: `DECISIONS.md BACKEND_PLAN.md`

## Phases (commit after each, `npm test` + `npm run check` green first)
1. Foundation: config, prng, events, clock, format, storage(+migrations), router, ui, CSS tokens/base, shell page, PWA files.
2. Core systems: rating, scoring, srs, benchmarks, daily, achievements, progress(finalize run), juice/audio/haptics, loop, gameShell + results, dummy game.
3. Quick Math (logic, view, numpad, juice).
4. Ballpark (parser, scoring, dot plot) then How Sure Are You? (Brier, calibration chart). Content banks.
5. Word Bank (+3 decks, SRS persistence) and Stroop.
6. Daily flow, Home recommendations, Stats, Settings, achievement wiring.
7. Content audit, a11y pass, perf pass, SW offline logic test, smoke script.
8. Docs (README, CLAUDE.md, BACKEND_PLAN). Stretch: Odds Check via plugin contract only.

## Risks
- Game-feel code is DOM-heavy and cannot be unit-tested → keep logic pure, verify views in the in-app browser, read each view for handler mistakes.
- Content correctness (facts, romanization) → write conservatively, audit pass, validators in tests.
- SW cache staleness → precache list + content hash generated by `scripts/gen-sw.mjs`, verified by a test; SW not registered on localhost unless `?sw`.
- Playwright is not installed here → smoke script skips cleanly; manual browser verification instead.
